# Fitur

Spese - Personal Finance Tracker

Fitur yang akan ditawarkan dan disajikan ke pengguna


> Tahap pengembangan 1
# Authentication

1. Daftar atau buat akun (email, password) atau menggunakan akun Google, auth supabase
2. Masuk / login (email, password) atau bisa menggunakan akun Google
3. Lupa password, verifikasi reset password via email terdaftar
4. Logout

# Fungsi utama

1. Menambahkan pengeluaran (Nama pengeluaran, kategori, tanggal, metode pembayaran(cash, tf bank, qris, etc.), jumlah, notes(opsional), bukti lampiran(opsional))
2. Menghapus pengeluaran (jika salah input dan sudah tersubmit)
3. Edit pengeluaran (jika salah input dan sudah tersubmit)
5. Tambah kategori custom
6. Mencari transaksi berdasarkan nama (Search), rentang waktu
7. Menambahkan pengeluaran rutin (Fitur otomatis yang bisa langsung memasukkan transaksi pengeluaran yang dapat diatur(daily - yearly) Ex: Monthly premium app subscription)
8. Set budgeting daily - yearly (Email notification kalo pengeluaran >% budgeting), otomatis reset nominal jika sudah melewati waktu budgeting

# Dashboard
1. Total pengeluaran, Grafik ringkasan pengeluaran, ada warna atau icon per kategori, bisa lihat akumulasi harian, mingguan, bulanan, tahunan.
2. Log pengeluaran yang recently dimasukkan atau dicatat
3. Pilihan menu kategori pengeluaran, sistem bisa memfilter sesuai dengan kategori yang dipilih
4. Selain fitur kategori, ada juga fitur sort, berdasarkan tanggal, jumlah, etc.

# Lainnya
1. Notifikasi email recap pengeluaran(daily - yearly)
2. Export recap pengeluaran ke excel atau PDF
3. Email notification kalo pengeluaran >% budgeting
